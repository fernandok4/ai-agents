# File Conventions

## Output Locations

| Agent | Output | Location |
|-------|--------|----------|
| frontend-developer | (code files) | As specified by user/spec |
| frontend-qa-engineer | (test files) | Project test directory |
| frontend-quality-reviewer | `quality-review.md` | Current directory |
| frontend-security-reviewer | `security-review.md` | Current directory |
| frontend-performance-reviewer | `performance-review.md` | Current directory |
| accessibility-reviewer | `accessibility-review.md` | Current directory |

## File Reference Format

When referencing code locations, use: `path/to/file.ext:lineNumber`

Examples:
- `src/components/UserCard/UserCard.tsx:42`
- `src/hooks/useAuth.ts:15`
- `src/pages/Dashboard/Dashboard.vue:88`
